Imperial Barber

Trabalho prático desenvolvido para a faculdade de Ciência da Computação por suellen-ag-dias.

Este é um protótipo de site para barbearia criado com HTML5, CSS3 e JavaScript puro. O sistema simula um ambiente completo de agendamento online, contando com controle de cadastro, login, calendário interativo e gerenciamento de horários.

Como o objetivo é focar no desenvolvimento front-end, o projeto não utiliza banco de dados externo ou servidor; todos os dados são salvos diretamente no navegador usando o armazenamento local (localStorage).
Funcionalidades principais

    Cadastro de usuários e sistema de login.

    Navegação entre as telas de início, agendamento, meus horários, serviços, sobre e avaliações.

    Calendário interativo que bloqueia datas passadas e domingos.

    Listagem e seleção de horários disponíveis conforme o serviço escolhido.

    Opção para consultar e cancelar agendamentos ativos.

    Mural de avaliações com notas e comentários.

    Layout adaptado para celulares, tablets e computadores.

Como executar

O projeto não exige instalação de programas, dependências ou uso de terminal.

    Baixe ou clone este repositório.

    Certifique-se de que os arquivos principais estão na mesma pasta.

    Abra o arquivo index.html diretamente em qualquer navegador web.
